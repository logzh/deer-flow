# DeerFlow

## Cursor Cloud specific instructions

### System dependencies

The VM requires: Node.js 22+, pnpm, `uv` (Python package manager), and nginx.
`uv` is installed to `~/.local/bin` — ensure `PATH` includes it (e.g. `export PATH="$HOME/.local/bin:$PATH"`).
nginx needs writable `/var/lib/nginx` directories; if you get a permission error on startup, run:
```
sudo mkdir -p /var/lib/nginx/body /var/lib/nginx/proxy /var/lib/nginx/fastcgi /var/lib/nginx/uwsgi /var/lib/nginx/scgi
sudo chown -R $(whoami):$(whoami) /var/lib/nginx
```

### Configuration

- `make config` requires `PYTHON=python3` on this VM (no `python` symlink).
- `config.yaml` must have at least one model entry under `models:` or the LangGraph server and several backend tests will fail with a Pydantic validation error.
- `.env` must uncomment and set `OPENAI_API_KEY` (or whichever provider key your model uses) — the config parser resolves `$OPENAI_API_KEY` at load time.

### Running the application

See the root `README.md` and `CONTRIBUTING.md` for standard commands. Key commands:
- `make check` — verify prerequisites (use `PYTHON=python3`)
- `make install` — install backend (`uv sync`) + frontend (`pnpm install`) dependencies
- `make dev` — start all 4 services (LangGraph :2024, Gateway :8001, Frontend :3000, Nginx :2026)
- Access the app at http://localhost:2026

### Lint / Test / Build

| Service  | Lint | Test | Build |
|----------|------|------|-------|
| Backend  | `cd backend && make lint` | `cd backend && make test` | N/A (interpreted) |
| Frontend | `cd frontend && pnpm lint` | No test framework configured | `cd frontend && pnpm build` |

- Backend tests in `test_client_live.py` require a real LLM API key and are expected to error without one.
- A few unit tests (`test_creates_agent`, `test_make_lead_agent_disables_thinking`) fail when `config.yaml` has no models — this is expected on fresh setups without API keys.
- Frontend typecheck: `cd frontend && pnpm typecheck`

### Gotchas

- The Makefile defaults `PYTHON` to `python` which doesn't exist on this VM. Always use `PYTHON=python3 make <target>` or alias `python` to `python3`.
- `serve.sh` uses `pkill -f` for cleanup — do not manually call `pkill -f` to stop services; use `make stop` instead, or send SIGINT to the `make dev` process.
- The frontend env file (`frontend/.env`) is generated by `make config` from `frontend/.env.example`; it sets `SKIP_ENV_VALIDATION=1` by default.
